Laravel Authentication Lab
Project: it-auth-lab

Copy each PHP and Blade file into the matching location in your Laravel project. The filenames are prefixed with their original folder paths so they are easy to identify.

Setup:
1. Create a MySQL database named it_auth_lab.
2. Set your database credentials in .env.
3. Copy the file contents into the matching Laravel paths.
4. Run php artisan config:clear, php artisan migrate, and php artisan serve.
